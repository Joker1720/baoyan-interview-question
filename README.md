# 🎓 保研面试 · 问题集

> 通信工程保研面试准备的专属问题管理工具

## 简介

一个轻量级的单页 Web 应用，帮助整理和复习保研面试中可能遇到的各种问题。所有数据存储在浏览器本地，无需注册、无需联网、无需后端。

## 在线访问

[https://joker1720.github.io/baoyan-interview-question/](https://joker1720.github.io/baoyan-interview-question/)

## 功能

### 问题管理
- **添加问题**：填写问题内容、分类、子分类、答案要点、掌握状态、标签
- **编辑/删除**：随时修改或移除已添加的问题
- **展开答案**：点击问题卡片即可展开查看答案，再次点击收起

### 分类体系

| 分类 | 涵盖方向 |
|------|---------|
| 专业知识 | 通信原理、信号与系统、数字信号处理、移动通信/无线通信、光纤通信、计算机网络、电磁场与电磁波、信息论与编码、通信电子线路、嵌入式/单片机、编程与算法等（可自定义添加） |
| 个人问题 | 自我介绍、科研经历、项目经历、择校动机、未来规划等 |
| 英语问题 | 英语自我介绍、专业英语问答、日常问答等 |
| 综合面试 | 时事热点、综合素质、压力面试等 |

### 筛选与搜索
- 按**分类 + 子分类**筛选
- 按**掌握状态**筛选（全部 / 未掌握 / 已熟悉 / 需复习）
- **关键词搜索**：支持搜索问题内容、答案和标签
- **排序**：按添加时间、最近更新、复习次数排序

### 专业知识分组展示
点击「专业知识」大类时，问题按课程分组展示，每门课可独立折叠/展开，方便按课程逐门复习。

### 掌握状态追踪
每个问题可标记三种状态：
- ❌ 未掌握
- ✅ 已熟悉
- 🔄 需复习

在问题卡片上可一键切换状态，页面顶部实时统计掌握进度。

### 面试模拟模式
点击「面试模式」进入模拟面试：
1. 选择要复习的分类
2. 点击「开始抽题」随机抽题
3. 思考后点击「显示答案」对照参考
4. 标记「已熟悉」或「需复习」自动进入下一题

### 数据共享
- **导出**：将所有问题导出为 JSON 文件
- **导入**：导入他人导出的 JSON 文件（支持替换或合并去重）
- 配合在线页面链接，团队成员可以共享题目库

### 示例数据
首次打开页面时会自动加载约 40 道常见面试题（含参考回答），覆盖所有分类。可通过左侧「重置示例数据」按钮重新加载。

## 使用说明

1. 打开网页链接
2. 浏览已有的示例问题，熟悉界面
3. 点击「添加问题」开始录入自己的问题
4. 按分类筛选，点击卡片展开答案进行复习
5. 使用「面试模式」模拟真实面试场景
6. 导出数据分享给同学，或导入同学的题目

## 技术实现

- 纯前端单页应用（HTML + CSS + JavaScript）
- 数据存储于浏览器 localStorage
- 无外部依赖，无需后端服务
- 响应式设计，支持电脑和手机

## 本地开发

```bash
git clone https://github.com/Joker1720/baoyan-interview-question.git
cd baoyan-interview-question
# 直接用浏览器打开 index.html 即可
```

修改 `index.html` 后提交推送，GitHub Pages 会自动部署更新。
